git clone создает удаленный репозиторий 
git status показывает текущее состояние фалов 
git add добовляет файлы в индекс
git commit сохранияет проиндексированные изменения 
git push отправляет локальные коммиты в удаленый репозиторий 
git pull загружает изменения из удаленного репозитория 
git init создает новый пустой Git репозиторий 
git log выводит историю коммитов
git branch показывает список веток или создает новую ветку 
git checkout переключается на указнную ветку или востоналивает конкретного коммита
